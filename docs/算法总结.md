# 贝叶斯变点估计 —— 算法总结

本文档总结 `贝叶斯变点估计.ipynb` 中实现的两套贝叶斯变点检测算法：

| 记号 | 算法 | 类型 | 推断方式 |
|---|---|---|---|
| **BOCPD** | Bayesian Online Changepoint Detection | 在线 / 逐点递推 | 运行长度后验精确递推 |
| **BPM** | 乘积划分模型（Product Partition Model） | 离线 / 全序列 | 分段边际似然 + 前向-后向精确后验 |

两者共享同一个建模思想：**变点把序列切成若干段，段内同分布，段间独立**。
区别只在「如何对分段结构做后验推断」：BOCPD 用在线递推只保留运行长度的一维后验，
BPM 用全序列的乘积划分结构做精确后验，能给出「同时考虑所有变点组合」的结论。

---

## 1. 问题定义

给定观测序列 $x_{1:T}$（本项目中为 A 股**周线对数收益率**），假设存在未知数量的变点

$$
0 = \tau_0 < \tau_1 < \cdots < \tau_m < \tau_{m+1} = T,
$$

把序列切成 $m+1$ 段 $[ \tau_{k}, \tau_{k+1}-1 ]$。每段内独立同分布（或服从同一参数模型），
段与段之间的参数独立。目标是求变点集合的后验分布 $p(\tau_{1:m} \mid x_{1:T})$。

复杂度主要来自两个未知量：**变点个数** $m$ 与**变点位置** $\tau$，二者的联合空间是
$O(2^T)$ 量级，因此必须借助共轭先验或递推结构才能精确计算。

---

## 2. 算法 A：BOCPD（在线贝叶斯变点检测）

### 2.1 运行长度

定义 **运行长度** $r_t$ = 当前段到 $t$ 时刻为止已持续的观测数（$t$ 是段内第几个点）。

$$
r_t =
\begin{cases}
0, & \text{若 } t \text{ 处发生变点（新段开始）} \\
r_{t-1} + 1, & \text{否则}
\end{cases}
$$

BOCPD 不去显式追踪变点集合，而是维护 $p(r_t \mid x_{1:t})$ 这个离散分布。
运行长度后验的「重置」直接对应变点，因此它天然是在线算法：每来一个新点，只需
$O(r_{\max})$ 的更新。

### 2.2 先验：hazard 与段长分布

设每个时刻发生变点的先验概率相同，为 hazard rate $H$（本项目默认 $H = 1/50$，
即平均每 50 周一段）。等价地，段长服从几何分布：

$$
P(\text{段长} = l) = H (1-H)^{l-1}, \qquad \mathbb{E}[\text{段长}] = 1/H .
$$

这个先验是**唯一**影响灵敏度/误报权衡的结构性假设：$H$ 越大越敏感、误报越多。

### 2.3 观测模型：Normal-Inverse-Gamma 共轭先验

段内观测假设为高斯：$x_t \sim \mathcal{N}(\mu, \sigma^2)$，对参数取共轭的 NIG 先验

$$
\mu \mid \sigma^2 \sim \mathcal{N}\left(\mu_0, \frac{\sigma^2}{\kappa_0}\right),
\qquad
\sigma^2 \sim \mathrm{Inv\text{-}Gamma}(\alpha_0, \beta_0).
$$

实现上不存后验参数，而存**充分统计量** $(n, S, Q)$，其中
$n$ 为段内点数，$S = \sum x_i$，$Q = \sum x_i^2$。更新一次只需 $O(1)$：

```python
NIGState(n + 1, S + x, Q + x * x)
```

由 $(n,S,Q)$ 恢复后验参数：

$$
\kappa = \kappa_0 + n,\quad
\mu = \frac{\kappa_0 \mu_0 + S}{\kappa},\quad
\alpha = \alpha_0 + \frac{n}{2},
$$

$$
\beta = \beta_0 + \frac{1}{2}\left(Q - \frac{S^2}{n}\right)
+ \frac{\kappa_0 n (\bar{x} - \mu_0)^2}{2\kappa},
\qquad \bar{x} = S/n .
$$

### 2.4 预测分布

边际化 $\mu,\sigma^2$ 之后，新观测的预测分布是 **Student-t**（闭式，无需采样）：

$$
x \mid (n,S,Q) \sim t_{\nu}\big(\mu,\; s^2\big),\quad
\nu = 2\alpha,\quad
s^2 = \frac{\beta(\kappa+1)}{\alpha \kappa}.
$$

即

$$
\log p(x \mid n,S,Q) =
\log\Gamma\!\left(\tfrac{\nu+1}{2}\right) - \log\Gamma\!\left(\tfrac{\nu}{2}\right)
- \tfrac12\log(\nu\pi) - \log s
- \tfrac{\nu+1}{2}\log\!\left(1 + \frac{z^2}{\nu}\right),\quad z = \frac{x-\mu}{s}.
$$

这是 BOCPD 能 $O(1)$ 更新单段的核心：共轭 + 充分统计量。

### 2.5 递推（对数域）

设 $R_{t-1}(r) = p(r_{t-1} = r \mid x_{1:t-1})$。新观测 $x_t$ 到达后：

**增长**（没有变点，运行长度 +1）：

$$
\tilde R_t(r+1) = R_{t-1}(r)\,(1-H)\, p\big(x_t \mid r_{t-1}=r\big),
$$

**重置**（发生变点，运行长度归零）：

$$
\tilde R_t(0) = H \sum_{r} R_{t-1}(r)\, p\big(x_t \mid r_{t-1}=r\big).
$$

归一化常数 $C_t = \sum_r R_{t-1}(r)p(x_t\mid r)$（即 $x_t$ 的预测证据，等于
$\log \sum$ 的 `logsumexp`）。实现全部在对数域完成，避免下溢：

```python
log_pred = [predictive_logpdf(x, s) for s in states]
log_joint = log(R) + log_pred
log_evidence = logsumexp(log_joint)
log_new_R[0] = log_evidence + log(H)          # reset
log_new_R[1:] = log_joint + log(1 - H)        # growth
log_new_R -= log_evidence
```

单步复杂度 $O(r_{\max})$，总复杂度 $O(T \cdot r_{\max})$；实现里对
`max_run_length` 做截断（默认 5000）以控制内存。

### 2.6 变点判据（以及一个必须知道的退化性质）

**常量 hazard 下 $R_t(0) \equiv H$。** 把归一化常数代回去：

$$
C_t = H\sum_r R_{t-1}(r)p(x_t\mid r) + (1-H)\sum_r R_{t-1}(r)p(x_t\mid r)
= \sum_r R_{t-1}(r)p(x_t\mid r),
$$

所以

$$
R_t(0) = \frac{H \sum_r R_{t-1}(r)p(x_t\mid r)}{C_t} = H .
$$

也就是说，**$R_t(0)$ 与数据无关，恒等于 hazard**，拿它做阈值检测（本 notebook 的
`cp_threshold = 0.5`）永远不会触发。这不是实现 bug，而是常量 hazard 模型的恒等式。

> 复现：`examples/demo_bocpd.py` 中 $R_0(t)$ 是一条严格的水平线 $0.02$。

真正携带信号的是运行长度后验的**形状**。可用判据：

1. **MAP 运行长度**（Adams & MacKay 原文的做法）：$\hat r_t = \arg\max_r R_t(r)$，
   发生变点时 $\hat r_t$ 会突然回落到 0 附近；
2. **短运行长度后验质量**：$S_t = \sum_{r \le k} R_t(r)$，含义是「当前段在最近 $k$ 期内
   重启过」的后验概率。稳定段内 $S_t \approx 0$，变点处接近 1。

本项目 `src/bocpd.py` 默认使用判据 2（`decision_rule="run_length"`，$k=8$），
再叠加「局部峰 + 最小间隔去重」得到离散变点；`decision_rule="r0"` 保留原 notebook 行为
用于对照。

### 2.7 参数与调参

| 参数 | 含义 | 经验取值 |
|---|---|---|
| `hazard H` | 每期变点先验概率 | $1/50$（周线），牛市/熊市切换频率高时可取 $1/30$ |
| `cp_threshold` | 判据阈值 | 0.5 起步；漏检多则降到 0.3 |
| `min_gap` | 相邻变点最小间隔 | 5–10（周），抑制同一事件多次触发 |
| `nig_mu0 / beta0` | NIG 先验中心 | 代码用全样本均值与方差做经验贝叶斯初始化 |
| `max_run_length` | 运行长度截断 | 5000，视数据长度可调 |

### 2.8 优点与局限

**优点**：天然在线（每期 $O(r)$）、无需知道变点个数、共轭闭式、不确定度完整保留。

**局限**：

- 每次只保留 $r_t$ 的边际后验，不做「多个变点联合」的推断；
- 段内模型为高斯，对收益率厚尾不够鲁棒（可换 Student-t 观测模型）；
- 检测存在滞后：变点后需要数个观测才能把质量推到短运行长度上；
- 常量 hazard 不适合「有周期性/有先验阶段」的场景，可换成 $H(r)$ 非恒定 hazard。

## 3. 算法 B：离线乘积划分模型（BPM）

### 3.1 乘积划分与段长先验

把「分段」视为对 $\{1,\dots,n\}$ 的一个划分。对任意段 $[s,t]$，段长先验取几何分布

$$
P([s,t]\ \text{是一个段}) = \lambda (1-\lambda)^{t-s},
$$

最后一个段不加 $\lambda$ 因子（后面没有变点）。$\lambda$ 与 BOCPD 的 hazard 同义，
默认 $1/60$ 量级。

### 3.2 段内模型：AR(p)

收益率序列有自相关，因此段内用 AR($p$)：

$$
y_t = \sum_{i=1}^{p}\beta_i x_{t-i} + \varepsilon_t,\qquad
\varepsilon_t \sim \mathcal{N}(0,\sigma^2),\qquad
\beta \sim \mathcal{N}(0,\delta^2 I).
$$

$p \in \{1,\dots,p_{\max}\}$（默认 $p_{\max}=2$）作为**模型平均**的一部分，
先验等权 $1/p_{\max}$。

### 3.3 分段边际似然（解析积分）

关键一步：把 $\beta$ 与 $\sigma^2$ 解析积分掉，得到只依赖数据的「段证据」。
令设计矩阵 $G \in \mathbb{R}^{n_{obs}\times p}$，响应 $y$，先验尺度 $\delta$，
$\sigma^2 \sim \mathrm{Inv\text{-}Gamma}(a, b)$，$a=v/2,\ b=\gamma/2$：

$$
\Sigma = (G^\top G + \delta^{-2} I)^{-1},\qquad
\Sigma_\beta = \sigma^2 \Sigma,
$$

$$
\log P(s,t,p) =
-\frac{n_{obs}}{2}\log(2\pi)
+ \frac12 \log|\Sigma|
- p\log\delta
+ a\log b - \log\Gamma(a) + \log\Gamma\!\left(a + \frac{n_{obs}}{2}\right)
- \left(a + \frac{n_{obs}}{2}\right)\log\!\left(b + \frac{y^\top P y}{2}\right),
$$

其中 $P = I - G\Sigma G^\top$ 是「去掉回归子空间后的投影残差」，
$y^\top P y$ 即残差平方和。这一步是整个离线算法能精确求解的前提：
**段与段之间的似然可以拆开相乘**。

### 3.4 前向-后向证据和

定义 $Q(s)$ 为「从 $s$ 到序列末尾」所有可能分段的加权证据之和（对数域）：

$$
Q(s) = \sum_{t=s}^{s+L-1} \lambda(1-\lambda)^{t-s}\,\frac{P(s,t,p)}{p_{\max}}\,Q(t+1)
\;+\; \underbrace{(1-\lambda)^{n-1-s}\,\frac{P(s,n-1,p)}{p_{\max}}}_{\text{最后一段}} .
$$

$Q(s)$ 从后往前一遍 DP 即可，复杂度 $O(nL \cdot p_{\max})$。
它同时是归一化常数，使后续采样无需再做积分。

### 3.5 精确后验采样（不是 MCMC）

有了 $Q$，在位置 $s$ 处下一段终点 $t$ 的后验概率是闭式的：

$$
P(\text{下一段结束于 } t \mid \text{从 } s \text{ 开始}) \propto
\lambda(1-\lambda)^{t-s}\,\frac{P(s,t,p)}{p_{\max}}\,\frac{Q(t+1)}{Q(s)} .
$$

于是从 $s=0$ 起逐段抽样、每抽一次段就前进一步，**一次遍历就能得到一条后验样本**。
重复 $k$ 次（默认 2000，可截掉 `burn_in`）得到变点配置的后验样本，再统计

$$
\hat p_t = \frac{1}{k}\sum_{j=1}^{k} \mathbb{I}\{\,t \in \tau^{(j)}\,\}
$$

即每个位置的**后验包含概率**。

> 注意：虽然常被称作「采样」，这里是从精确后验做**独立同分布抽样**，
> 不存在 MCMC 的自相关与收敛问题——$Q$ 已经把全部后验信息压缩好了。

### 3.6 变点判据

1. 取后验概率的**严格局部极大**（$p_t > p_{t-1}$ 且 $p_t > p_{t+1}$），保证一一对应；
2. 按概率降序，只保留 $p_t > p_c$（默认 0.5）的候选；
3. 与已选变点的距离小于 `min_gap`（默认 8）则丢弃。

### 3.7 复杂度

| 步骤 | 复杂度 | 说明 |
|---|---|---|
| 边际似然矩阵 | $O(nL \cdot p_{\max})$ 次模型拟合，每次 $O(n_{obs}^2 p + p^3)$ | 主导项 |
| 前向-后向 | $O(nL \cdot p_{\max})$ | 纯加法，很便宜 |
| 采样 $k$ 次 | $O(k \cdot m \cdot L \cdot p_{\max})$ | $m$ 为段数 |

$L$ = `max_segment_length` 截断长度。$n=300$、$L=120$、$k=1500$ 在单核上约 6 秒。
$n$ 增大时是二次增长，可以（a）减小 $L$；（b）用 QR/Woodbury 把每次
$O(n_{obs}^2)$ 的投影降到 $O(n_{obs}p^2)$。

### 3.8 优点与局限

**优点**：变点个数与位置联合推断、后验概率可解释（0.8 = 80% 的采样在此处断开）、
AR 结构能区分「均值漂移」和「自相关结构变化」、无需初值。

**局限**：全量重算、$O(n^2L)$ 较重、变点位置在真实边界附近几期内分散（单个位置的
后验峰可能低于 0.5，需适当放宽阈值或看窗口累计质量）、对 $p_{\max}$ 与 $\lambda$ 敏感。

## 4. 两个算法的对比

| 维度 | BOCPD | BPM（离线） |
|---|---|---|
| 推断对象 | $p(r_t \mid x_{1:t})$（运行长度） | $p(\tau_{1:m} \mid x_{1:n})$（变点集合） |
| 在线/离线 | 在线，逐点 $O(r)$ | 离线，整体重算 |
| 段内模型 | 高斯 + NIG 共轭 | AR(p) + Normal-Gamma |
| 变点个数 | 由 hazard 隐式决定 | 由 $\lambda$ 先验与后验共同决定 |
| 输出 | 变点概率曲线、MAP 运行长度 | 每个位置的后验包含概率 |
| 复杂度 | $O(Tr_{\max})$ | $O(n^2L)$ |
| 适合场景 | 实时监控、预警 | 事后复盘、结构性归因 |

## 5. 本项目在 A 股周线上的处理流程

```
baostock 周线（前复权） → 收盘价 close
      → 对数收益率 r_t = log(close_t / close_{t-1})
      → 变点检测（收益率序列上）
      → 索引映射回价格序列：price_index = return_index + 1
      → 分段收益 / 分段波动 / 趋势标签
      → 图表（价格+变点、变点概率、MAP 运行长度、分段收益、市场状态散点）
      → CSV + 文本报告
```

把变点检测放在**收益率**而不是价格上，是因为价格非平稳、有趋势，而收益率近似平稳，
高斯/AR 模型的假设更成立。可视化再映射回价格轴，便于读图。

## 6. 合成数据实验

**BOCPD**（`examples/demo_bocpd.py`，$n=520$，$H=1/50$，3 个真实变点）
- 检测结果：123 / 250 / 409，真实 120 / 260 / 400，3/3 命中（±15 期）
- $R_0(t)$ 全程恒为 0.02（验证第 2.6 节的恒等式）
- 短运行长度后验在变点处由 ~0.05 跳到 0.6–0.98

**BPM**（`examples/demo_offline.py`，$n=300$，AR(1) 系数 0 → 0.9 → −0.5）
- 检测结果：109 / 193，真实 100 / 200，2/2 命中
- 后验概率峰：0.84 / 0.36，其余位置接近 0
- 耗时约 6 秒

## 7. 实现注意事项（踩坑记录）

1. **$R_t(0) \equiv H$**：见 2.6。用 $R[0]$ 做阈值必然失效，必须换 MAP 运行长度或
   短运行长度质量。这是本项目原 notebook 中「总检测不到变点」的直接原因。
2. **对数域归一化**：所有递推在 log 空间做，`logsumexp` 归一化；先验均值+方差用
   全样本做经验贝叶斯初始化，避免量纲不匹配造成的假变点。
3. **段长截断**：BPM 的 `max_segment_length` 既控制复杂度，也隐含「没有超长段」的
   先验假设，过长会拖慢、过短会强行切段。
4. **启动伪影**：$t<k$ 时运行长度不可能超过 $t$，短运行长度质量恒为 1，必须跳过。
5. **阈值与局部极大**：BPM 的后验在真边界附近几期内分散，单个位置可能到不了 0.5；
   与其硬调阈值，不如看窗口累计概率 $P(\tau \in [t-w, t+w])$。
6. **notebook 的 raw cell**：原 notebook 第一格被保存为 `raw` 类型，Jupyter 不会执行；
   若要整段运行需手动改成 `code`。本仓库 `src/` 中是从中抽取的、可直接 import 的实现。

## 8. 可继续改进的方向

- **厚尾观测模型**：BOCPD 用 Student-t 或 GARCH 残差替代高斯，降低极端值误报；
- **非恒定 hazard**：$H(r)$ 随运行长度变化（长段更易结束），同时消除 $R[0]$ 退化；
- **多变量变点**：对收益率向量（多股票/多因子）用多元 NIG 或因子结构；
- **加速 BPM**：QR 分解或 Woodbury 恒等式，把边际似然从 $O(n_{obs}^2)$ 降到 $O(n_{obs}p^2)$；
- **变点个数先验**：用 Poisson/Beta 过程替代几何段长，直接控制 $m$；
- **在线 BPM**：把 $Q(s)$ 截断成滑动窗口，得到「离线的精确性 + 在线的速度」。
