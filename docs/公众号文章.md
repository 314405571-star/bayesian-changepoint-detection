# 上证 16 年，只换了 18 次「规矩」

> 备选标题：
> - 《不预测涨跌，只判断"现在还是不是原来的市场"》
> - 《一个恒等于常数的"变点概率"：BOCPD 里最容易踩的坑》
> - 《859 根周线，19 段行情：用贝叶斯变点给 A 股分段》

---

先看一组数字。

上证指数，2010 年 1 月到 2026 年 10 月，859 根周线，**只涨了 15.47%**。

十六年半，年化不到 1%。

但如果把这 859 周切成 19 段，你会看到：有 8 段是涨的，11 段是跌的；涨得最猛的一段 21 周涨了 36%，跌得最狠的一段 53 周跌了 22%；同样是指数，2015 年那段时间的周波动率是 5.18%，而 2016–2018 年只有 1.74%。

**同一个指数，完全是两种生物。**

这篇文章讲的不是怎么预测涨跌，而是一个更基础的问题：

> 你手里这套参数、这个模型、这条均线，现在还适用于当前的市场吗？

---

## 一、策略失效，很多时候不是策略错了

做量化的人大概都经历过：回测漂亮的策略，上线三个月就开始回撤。

第一反应是改参数。改成 20 日、60 日、120 日，再回测，又好看了；上线，又失效了。

问题往往不出在参数上，而出在一个默认假设：**市场的行为规则在一段时间内是稳定的**。均线用 60 日，隐含假设是「60 天的样本足以刻画当前状态」；因子用 250 日滚动窗口，隐含假设是「一年一个周期」。

可市场并不按这个节奏换挡。2015 年 6 月到 7 月，三周之内波动率翻倍；2018 年初，趋势毫无预兆地反转；2020 年 7 月之后，指数横了 184 周。

**变点检测（changepoint detection）** 要回答的就是：数据自己什么时候换了规矩？

---

## 二、直觉：每来一根 K 线，问两个问题

贝叶斯在线变点检测（BOCPD，Adams & MacKay, 2007）的思路非常朴素。

每来一个新的观测，我们只问一件事：

> 这个点，是**当前这一段**里的又一个点，还是**新一段**的第一个点？

为此引入一个量叫**运行长度**（run length）：当前这一段已经持续了多少期。

- 如果没发生变点：运行长度 +1；
- 如果发生了变点：运行长度归零。

BOCPD 不去猜变点的位置，而是维护一个概率分布：**运行长度等于 0、1、2、3…… 的概率各是多少**。

每来一个新点，这个分布发生两件事：

1. **增长**：原来的每个运行长度 +1，权重乘以「没有变点」的概率；
2. **重置**：所有运行长度的质量，按 hazard 比例汇入运行长度 0。

用文字写出来就是：

```
新段(r+1) 的权重  ∝  上一期(r) 的权重 × (1 - H) × 该段对新点的预测概率
新段(r=0) 的权重  ∝  Σ 上一期各段的权重 × H × 该段对新点的预测概率
```

这里的 H 是 **hazard rate**：每一期发生变点的先验概率。取 H = 1/50，意思是「平均每 50 周换一次规矩」。这是整个模型里唯一需要人拍板的先验。

那么「预测概率」怎么算？

假设段内收益率服从正态分布，参数用**共轭的 Normal-Inverse-Gamma 先验**。共轭的好处是：后验有闭式解，把参数积分掉之后，新数据的预测分布是 **Student-t**，一步更新只需要 O(1) 的加法。

不需要采样，不需要迭代，不需要调学习率。一根周线进来，微秒级算完。

这就是它叫**在线**变点检测的原因。

## 三、一个坑：那个恒等于常数的「变点概率」

到这里，绝大多数教程（包括我最初写的版本）都会做一件看起来很自然的事：

把「运行长度 = 0 的概率」当作变点概率，画成一条曲线，超过 0.5 就报警。

代码大概长这样：

```python
if cp_prob > 0.5:
    print("变点！")
```

然后你会发现：**它永远不报警。**

我一开始以为是自己写错了，查了三天堆栈，最后发现是数学问题。

设 R(r) 是上一期的运行长度后验，p(x|r) 是各段对新观测的预测密度，那么：

```
R_new(0)  =  H × Σ_r R(r) × p(x|r)  /  C

C         =  Σ_r R(r) × p(x|r) × [ H + (1 - H) ]
```

注意分母方括号里的 H + (1−H) = 1。所以分母就等于分子去掉 H：

```
R_new(0)  =  H × Σ / Σ  =  H
```

**在常量 hazard 下，R(0) 恒等于 H，与数据完全无关。**

H = 0.02，那这条曲线就是一条 0.02 的水平直线。阈值卡 0.5，一辈子都触发不了。

这不是 bug，这是模型的一个恒等式。有人把它当成开源库的 bug 提交过 issue，也有很多 BOCPD 实现因此「检测不到变点」。

> 顺带说一句：如果你把 hazard 改成随运行长度变化的 H(r)（长段更容易结束），这个退化就消失了。但常量 hazard 下它一定成立。

### 那该看什么？

变点发生时，真正变化的是**运行长度分布的形状**，而不是 0 位置的那一格。

两个可用的判据：

1. **MAP 运行长度**：取概率最大的那个运行长度。变点之后，它会被打回 0 附近，然后重新往上爬——像锯齿。
2. **短段累计概率**：P(r ≤ k)，即「当前这一段在最近 k 期内重启过」的后验概率。稳定段里它接近 0，变点处会跳到接近 1。

我最终用的是第二个，取 k = 5 周。理由很实在：**它可解释**——「当前段落很可能是最近 5 周内开始的」，这句话可以直接讲给别人听。

## 四、上证 16 年，实测

数据：baostock 周线、前复权，2010-01-08 至 2026-10-23，859 根。

在**对数收益率**上跑（不是价格——价格非平稳，收益率近似平稳），再把索引映射回价格轴。

参数：H = 1/50，k = 5，判定阈值 0.2，变点最小间隔 8 周。

结果：**18 个变点，19 段行情**。平均每 48.7 周换一次规矩，最短 8 周，最长 184 周。

```
检出时间      P(r≤5)   行情
2015-07-03    0.947    杠杆牛见顶、股灾开始
2018-02-09    0.971    去杠杆熊市起点
2024-09-27    0.992    政策底后的急速反弹
2024-02-23    0.719    长期阴跌结束
```

几段值得单独看：

**2015 年 2 月 – 6 月**：21 周，+36.31%，周波动 5.18%。

**2015 年 7 月 – 9 月**：13 周，−16.13%，周波动 5.56%。

**2016 年 1 月 – 2018 年 2 月**：105 周，+19.34%，周波动 1.74%。

2015 年的波动率是 2016–2018 年的**三倍**。用同一个止损阈值去管这两段行情，必然有一段是错的。

**2020 年 7 月 – 2024 年 2 月**：184 周，−15.29%，周波动 1.98%。

这是全样本最长的一段，也是「长期没有换规矩」的典型：三年半，指数在 3000 点上下磨，任何趋势策略在这段都要被反复打脸。

### 一个必须说清楚的滞后

变点检测不是水晶球。它需要**证据**，所以有滞后：

- 2015-07-03 检出，股灾实际在 6 月中就开始；
- 2018-02-09 检出，基本同步；
- 2024-09-27 检出，几乎同步（因为涨得太急）。

**它告诉你「已经变了」，不告诉你「将要变」。**

## 五、在线 vs 离线：两种贝叶斯方法

仓库里其实实现了两套方法，思路不同，用途也不同。

**在线 BOCPD**（本文主线）

- 每来一根 K 线更新一次，复杂度 O(T × 运行长度上限)；
- 输出变点概率曲线和 MAP 运行长度；
- 适合实时监控、盘中预警；
- 缺点：只看运行长度的边际后验，不做「多个变点联合」的推断。

**离线乘积划分模型**（另一套）

- 把整条序列的变点集合当作一个整体来推断；
- 段内用 AR(p)，回归系数和方差解析积分掉，得到每段的**边际似然**；
- 用后向递推算 Q(s)（后缀证据和），再逐段从**精确后验**抽样；
- 输出每个日期的**后验包含概率**，比如 0.84 表示 84% 的样本认为这里是断点；
- 缺点：全量重算，复杂度 O(n²L)，300 个点大约 6 秒。

一句话区分：**BOCPD 是传感器，离线模型是复盘工具。**

## 六、诚实的局限

写这类文章，最怕把工具说得太神。几条必须说：

1. **变点 ≠ 买卖点。** 检测到「波动率变了」，不代表该做多还是做空。它只描述状态，不预测方向。本文所有结果不构成任何投资建议。
2. **它只能发现「统计规律变了」，发现不了「为什么变」。** 政策、流动性、情绪，模型看不见。
3. **高斯假设不够用。** A 股周线明显厚尾。这份实测里，平方收益率的 lag-1 自相关是 0.2441，波动聚集很强，所以我在 NIG 的预测方差里混入了 EWMA 条件方差（λ = 0.94）做修正——也就是图里标的「ARCH 感知」。
4. **参数敏感。** H 决定灵敏度：H 取 1/30 会更早报警，也会更多误报；阈值 0.2 是在「不错过」和「不狼来了」之间的一次取舍。
5. **滞后不可避免。** 上面已经说过，这不是缺陷，是贝叶斯推断的代价。

```bash
pip install -r requirements.txt
python examples/demo_bocpd.py      # 合成数据演示
```

作为库调用：

```python
from src.bocpd import BOCPDConfig, BOCPDDetector

det = BOCPDDetector(BOCPDConfig(hazard=1/50, short_run_k=5, cp_threshold=0.2))
det.fit(weekly_returns)

det.short_run_probs      # P(r_t ≤ 5)，真正有判别力的判据
det.map_run_lengths      # MAP 运行长度

# 实盘：每来一根周线调一次
step = det.online_step(new_return)
```

## 最后

市场不缺预测涨跌的声音，缺的是对「**现在处于什么状态**」的诚实判断。

16 年，18 次换规矩。平均每次四十多周，但有时三周就天翻地覆，有时三年半纹丝不动。

如果你的模型假设「规矩是固定的」，那它大概率会在最需要它的那三周里，给你最差的答案。
